**Najciekawsze ptaki świata (subiektywnie)**

**Kilka słów o projekcie:**
Projekt przedstawia subiektywny wybór najciekawszych ptaków świata. Każdy z nich został krótko opisany w formie artykułu oraz zbioru ciekawostek. Przy każdym gatunku został uwzględniony odnośnik do odpowiedniego artykułu na Wikipedii.

**Funkcjonalności w JS:**
**Galeria zdjęć**– możliwość przeglądania zdjęć w obrębie każdego artykułu.
**Quiz**– interaktywny quiz sprawdzający wiedzę o ptakach.
**Przycisk powrotu na górę strony** – ułatwienie powrotu do panelu nawigacji dla mniejszych urządzeń.

**Wykorzystane technologie:**
HTML – struktura i zawartość strony.
CSS – wygląd strony i responsywność zależna od wielkości ekranu.
JavaScript – obsługa interaktywnych elementów oraz quizu.
